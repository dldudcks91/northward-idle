# WOS 참고 아트·화면 전면 개편

2026-10-04. 사용자는 모든 아트를 더 귀여운 WOS 캐릭터 참고 화풍으로 교체하고, 기본 UI의 강한 AI 느낌도 WOS UI를 참고해 모두 수정하라고 요청했다. 시간보다 명확한 수정 결과를 우선한다. 아래 구체적인 구도·수량·색·배치는 실행자가 정한 제작 기준이다.

## 실제 확인한 참고 화면

WOS는 Whiteout Survival로 해석했다. [공식 영웅 목록](https://www.whiteoutsurvival.wiki/heroes/)의 Jessie·Sergey·Molly 초상을 열어 큰 눈·둥근 얼굴·두툼한 겨울옷·크림색 모피·부드러운 입체 표현을 확인했다. [Google Play 게임 소개](https://play.google.com/store/apps/details?id=com.gof.global&hl=en)의 공개 이미지로 밝은 색과 단순한 오브젝트 표현을 확인했다.

UI는 홍보 이미지에서 추정하지 않고 [Google Play의 탐험 소개](https://play.google.com/store/apps/editorial?hl=en_NZ&id=mc_games_editorialevergreen_whiteout_survival_all_about_exploration_postinstall_fcp)의 실제 탐험 선택·자동전투·월드 화면을 열어 확인했다. 큰 설원 장면, 상단의 짧은 수치 HUD, 하단의 지역 경로, 두꺼운 프레임과 입체 버튼, 초상·체력 바가 중심이다. 여기에서 도출한 신작의 화면 배치는 실행자의 해석이다.

참조 파일과 내려받은 URL·시점은 `artifacts/reference/wos/sources.json`에 있다. 파일 이름 중 `formation-ui.webp`는 실제 탐험 선택 화면, `exploration.webp`는 실제 자동전투 화면, `hero-ui.webp`는 실제 월드 화면이다. 참고 캐릭터·화면을 게임용 에셋으로 쓰지 않고 고유한 여행자와 북방 풍경을 만든다.

## 아트 기준

- 캐릭터는 부드러운 3D 게임 일러스트, 둥근 실루엣과 맑은 표정으로 통일한다. 이전의 검은 외곽선·각진 면 음영·어두운 색을 대체한다.
- 파랑 겨울옷, 따뜻한 주황, 크림색 모피로 차가운 설원 속 온기를 표현한다. WOS 특정 캐릭터의 얼굴·의상을 재현하지 않는다.
- 곰·늑대·멧돼지·사슴은 귀·주둥이·다리·뿔 등 종별 형태를 살린다. 인간형 갑옷 몬스터로 바꾸지 않는다.
- 초상 6종과 지역별 풍경 6종을 독립적으로 생성한다. 지역마다 해변·침엽수림·얼음 호수·이탄습지·설산·북극광 유적을 구별한다.
- 초상은 실제 투명 PNG 원본과 알파를 보존한 WebP를 사용한다. 배경에는 UI·글자·버튼·인물을 그려 넣지 않는다. UI는 실제 상태와 코드로 표시한다.
- 메뉴·재료·장비 아이콘은 기존 SVG 원본을 색이 채워진 게임 아이콘으로 다시 그린다. 장식은 상태를 전달하는 데 필요한 만큼 사용한다.
- 이전 원본·파생 파일은 보존하고 v2 경로와 생성 목록을 적용한다. 생성 프롬프트·출처·알파·해시는 [아트 목록](../../assets/manifest.json)에 기록한다.

## 화면 기준

이전 세 열 대시보드와 동일한 카드 반복을 대체한다. 상단에는 주인공·체력·식량·습격 시각을 모으고, 중앙에는 지역 장면과 실제 선택을 크게 배치한다. 준비 안내는 한 곳에만 둔다. 영문 장식 제목과 반복적인 기술 설명을 제거한다. 기본 파란색 북방 분위기와 실제 활동 진행은 유지한다.

| 화면 | 실제 표현과 행동 |
|---|---|
| 탐험 | 선택한 지역 풍경과 주인공, 여섯 지역 경로, 조건과 첫 돌파·반복 탐험 버튼. 현재 지역과 선택 지역을 구별한다. |
| 전투 | 장면 위의 적·주인공, 체력·행동·자동 기술·피해. 같은 전투 노드를 유지해 Focus Stop이 끊기지 않는다. |
| 채집 | 지역별 활동과 큰 활동 아이콘, 산출·숙련·진행·시작 버튼. |
| 제작 | 작업대와 입력 재료→결과, 실제 재고·예약분·횟수. 부족 재료에서 준비 활동으로 이동한다. |
| 장비 | 큰 여행자와 세 장비 슬롯, 실제 비교·장착·태세 선택. |
| 가방·도감 | 아이템 슬롯과 적 초상·숙련을 중심으로 읽는다. 종류·수량·출처를 확인할 수 있다. |
| 기록·복귀 | 자세한 기록과 실제 산출·소모·손실·수비 결과. 계산 상한과 확인 저장을 유지한다. |
| 설정·복구 | 읽기 쉬운 게임 패널. 저장·내보내기·가져오기·취소·원본 복구·동작 감소를 계속 사용할 수 있다. |

내용 패널은 밝은 크림·얼음빛, 바깥 프레임은 청강색을 사용한다. 주요 버튼은 주황 또는 선명한 파랑과 눌림·하이라이트를 가지며 글자 대비를 확보한다. 작은 화면에서도 큰 터치 영역, 가로 넘침 없는 HUD·격자·모달, 메뉴 초점·Escape·닫힌 메뉴의 inert를 확인한다.

## 완료 조건

1. 현재 게임에서 참조하는 모든 기존 아트가 새 아트로 바뀌고 여섯 지역이 시각적으로 구별된다.
2. 모든 메뉴·전투·모달·복귀·시작 및 오류 화면이 새 표현을 사용한다. 기존 색만 바꾼 결과로 종료하지 않는다.
3. 실제 브라우저에서 1440·768·390px 화면을 확인하고 채집→제작→장착→탐험, 메뉴 이동 중 진행, Focus Stop, 저장과 복귀를 검증한다.
4. 기존 게임 저장 키·스키마·콘텐츠 ID·경제·전투 규칙을 유지한다. 이전 저장의 미완료 활동도 계속할 수 있다.
5. 실제 검수한 범위와 남은 제약을 [진행 상태](../PROJECT_STATUS.md)에 기록한다.
