# 화면 제작 기준

[현재 기획](GAME_DESIGN.md)이 게임 방향의 기준이다. 2026-10-04 사용자는 이전 완성본의 아트와 UI를 WOS(Whiteout Survival) 참고로 모두 다시 만들라고 요청했다. 구체적인 참고 이미지와 변경 근거는 [개편 기준](VISUAL_REDESIGN.md)에 있다. 실제 확인한 결과는 [진행 상태](../PROJECT_STATUS.md)에 기록한다.

## 사용자 확정 방향

- 파란색 북방 배경을 유지하면서 WOS의 귀여운 캐릭터와 게임 화면을 참고한다.
- 현재 화면의 강한 AI 느낌을 줄이는 전면 개편을 수행한다. 색상만 바꾸는 수정에 그치지 않는다.
- 2026-10-05 추가 요청에 따라 쓸데없는 설명을 모든 메뉴에서 제거한다. 소개문·분위기 문장·반복 안내·구현 설명을 상시 화면에 두지 않는다.
- 한 명의 주인공이 자동전투를 수행하고, 앞으로 나감·잠깐 멈춤·타격·복귀의 Focus Stop을 관전한다.
- 화면 이동과 활동 변경은 별개다. 다른 메뉴를 보거나 관전을 줄여도 접속 중 탐험·수비와 실제 보상은 같은 규칙으로 진행한다.
- 돌아오면 오프라인 활동·수비의 실제 결과를 확인한다.

## 실행자가 정한 개편 구조

큰 지역 장면과 캐릭터가 화면의 중심이다. 데스크톱에는 간결한 게임 아이콘 메뉴, 상단의 주인공·체력·보급·습격 HUD, 중앙의 지역 또는 선택한 작업, 하단의 현재 활동을 배치한다. 중복 대시보드·영문 장식 제목·상시 소개 패널 없이 지금 할 수 있는 행동과 조건을 먼저 읽게 한다.

화면은 제목·아이콘·수치·시간·비용·입력·버튼으로 구성한다. 조건과 실패 이유는 해당 행동 가까이 짧게 표시하며, 가능한 행동에 성공 안내 문장을 매번 붙이지 않는다. 소개문을 제거한 패널은 빈 큰 상자로 남기지 않고 묶음을 줄이거나 없앤다. 자동 보급의 품목/가격·씨앗 재고·보상 공간·첫 돌파 오프라인 상태, 저장 교체/초기화의 결과처럼 판단에 필요한 정보는 남긴다.

탐험은 각 지역의 새 풍경 위에 여행자·현재 위치·여섯 지역 경로와 행동 버튼을 배치한다. 선택한 지역과 실제 현재 지역을 구별한다. 지역 선택은 화면만 바꾸고, 이동·탐험 버튼이 실제 명령을 보낸다. 잠금·공격·방어·보온·숙련·음식 품질 조건과 첫 돌파·반복 탐험의 구분을 행동 가까이 보여준다.

채집은 지역별 작업과 큰 활동 아이콘, 제작은 입력 재료→결과와 횟수, 장비는 큰 여행자와 세 슬롯, 가방은 아이템 격자, 도감은 적 초상과 숙련을 중심으로 각각의 쓰임새에 맞게 구성한다. 제작의 부족 재료를 누르면 원료 채집·가공 활동으로 이동한다. 이미 예약한 제작 재료와 추가 제작에 필요한 재고를 구별한다. 활동·입력·선택 초점은 주기적인 상태 갱신 중에도 유지한다.

프레임과 HUD에는 청강색·밝은 파랑, 내용에는 크림색·얼음빛 패널, 주요 버튼에는 주황 또는 선명한 파랑을 쓴다. 버튼은 두꺼운 테두리·하이라이트·눌림이 있고, 아이콘은 색이 채워진 면과 둥근 형태로 다시 그린다. 내용의 명암, 잠금·소모·위험·선택 상태를 색뿐 아니라 텍스트와 기호로도 읽을 수 있어야 한다.

760px 이하에는 접근 가능한 메뉴를 제공한다. 닫힌 메뉴는 inert, 메뉴를 열면 첫 항목으로 초점 이동, 배경은 inert로 막고 Tab/Shift+Tab은 메뉴 안에서 순환한다. Escape로 닫으면 메뉴 버튼으로 초점을 돌린다. 작은 화면의 터치 영역·격자·HUD·대화 상자를 실제 브라우저에서 확인한다.

## 영구 마을 화면 · 1.1.0

아홉 번째 주요 활동 영역으로 마을을 추가하며 전체 메뉴는 9개다. 마을 안에는 시설·창고·교역·보급·농사·의뢰의 6탭을 둔다. 새 WOS 참고 설원 마을 풍경 위에 12개 시설을 선택하고 선택한 시설의 현재 효과·다음 비용·예약·시간·수리를 표시한다. 수리 비용은 펼쳐 확인하며 화면 갱신과 수리 직후에도 펼친 상태를 유지한다.

창고는 실제 자원별 양·공간 배분·건설 예약·예측 생산/소비를 표시한다. 순위 버튼이 단순 목록 정렬이 아니라 보관 한도를 바꾼다는 안내를 붙인다. 기부·버리기 수량과 교역 횟수는 생산 중에도 입력값과 초점이 유지돼야 한다. 빈 공유 공간이 다른 자원 몫일 수 있고, 현재 한도에 닿은 이유를 설명한다.

보급은 품목·실제 교역 가격·가방 목표 재고·다음 생산 시각을 보여준다. 농사는 빈 밭·성장·수확 대기·자동 재파종·씨앗 부족을 실제 상태로 표시하고 씨앗을 누르면 구입 경로로 이어진다. 의뢰는 진행과 납품 비용·보상·한 번 수령을 구분하고, 보상 공간 부족을 행동 근처에서 설명한다. 도감은 실제 수집/처치 기록, 작업 화면은 활동 마스터리, 기록은 마을·농사·목표 누계를 보여준다.

복귀 요약은 가방과 마을 원장을 분리하고 마을 생산·소비·수용하지 못한 자원·교역·세금, 농사·활동 숙련을 포함한다. 마을 관리 이동 버튼으로 실제 요약 확인을 저장하고 이동한다. 첫 돌파를 오래 보존한 복귀의 재로드도 저장 오류 없이 이어져야 한다.

## 전투와 복귀

전투는 지역 장면과 위쪽의 적·아래쪽의 여행자, 체력·행동 게이지·자동 기술·피해 숫자가 중심이다. 같은 전투의 초상과 연출 노드를 유지하고 수치·사건만 갱신한다. 보급이나 조건 문구가 바뀌어도 650ms Focus Stop을 중간에 제거하지 않는다. 동작 감소·숨겨진 탭·화면 이동은 시간·난수·보상을 바꾸지 않는다.

관전하지 않는 동안의 누적 공격은 전부 다시 재생하지 않는다.실시간 사건 연출과 복귀 결과는 분리한다. 전투·수비·회복 중 장비와 태세 변경 제한, 음식 자동 회복과 품질, 네 번째 공격의 자동 기술은 실제 상태에 연결한다.

복귀는 실제 계산 시간, 산출·소모·손실, 습격·수비 승패·작업 중단을 요약한다. 최대 7일 적용 시간과 제외 시간을 구별한다. 요약을 확인하면 실제 pendingSummary 확인을 저장한다. 자세한 사건은 기록 화면에서 읽고 다음 준비로 이어간다.

시작·오류·중복 창·저장 복구·새 여정 확인 대화 상자도 같은 게임 패널을 사용한다. 저장 원본 보관·취소·정상본 복구·가져오기·내보내기를 계속 사용할 수 있어야 한다. 개발 시간 가속·ID·저장 버전·디버그 로그는 일반 화면에 표시하지 않는다.

## 실제 검수

게임의 실행 방법은 루트 README를 따른다. 1440·768·390px에서 마을 포함 9개 메뉴를 실제로 열어 보고, 버튼으로 채집→제작→장착→탐험, 메뉴 이동 중 진행, Focus Stop, 설정·복귀·복구를 검증한다. 마을의 6탭과 경험치·남은 단계 문구가 둥근 패널에 잘리지 않는지도 확인한다. 여섯 지역을 선택해 고유한 배경 적용을 확인하고, 개편 전의 실제 저장을 불러와 자원·장비·숙련·난수·진행을 보존하는지 확인한다. 이미지 생성과 합성 미리보기 검수는 [아트 기준](ART_DIRECTION.md), 브라우저 검증은 [검증 기준](../engineering/VALIDATION.md)을 따른다.
