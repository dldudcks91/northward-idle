# 프로젝트 진행 상태

갱신: 2026-10-05

## 현재 단계

**북방의 마지막 봉화 1.1.0 — 전체 UI 설명 정리 완료.** 이번 수정 후 브라우저 흐름 34개·전체 화면 44개·마을 50개, 총128개가 통과했고 실행 오류와 리소스 요청 오류는 모두0이다. 앞선 Township 제작의 엔진·저장·경제 76개 통과 결과는 유지하며, 이번에는 해당 소스를 변경하지 않아 다시 실행하지 않았다.

사용자가 요청한 영구 마을의 생산·시설·창고·교역·보급을 주인공의 채집·제작·탐험·수비에 연결했고, 독립 농사·활동별 마스터리·실제 수집/처치·의뢰와 장기 목표를 추가했다. 다중 에이전트가 엔진·화면·아트를 나누고 별도 코드/플레이 감사를 수행했다. 수·단계·경제·시간은 위임 범위에서 실행자가 정한 세부안이다. [기획](design/GAME_DESIGN.md), [확장 규칙](design/TOWNSHIP_EXPANSION.md), [결정 D-014](DECISIONS.md)에 근거를 기록했다.

실행은 **[게임 시작.bat](../게임%20시작.bat)** 또는 `python scripts/serve.py --open`. 주소는 `http://127.0.0.1:8765`이며 기존 탭은 Ctrl+F5로 새 화면을 불러온다. [플레이 안내](PLAY_GUIDE.md)에 마을과 농사 사용법이 있다.

사용자 요청으로 로컬 Git 저장소와 `main` 브랜치를 만들고 [GitHub 저장소](https://github.com/dldudcks91/northward-idle)를 `origin`으로 등록했다. 게임 코드·아트·기획·검증 스크립트를 버전 관리하며, 로컬 도구와 생성 검증 결과는 기존 `.gitignore`에 따라 제외한다.

## 이번 UI 수정

9개 메뉴·마을6탭·활동 표시·설정·초기화·복귀·저장 복구 화면에서 소개문, 분위기 문장, 영문 장식 제목, 반복 안내와 설명 툴팁을 제거했다. 설명 패널 자체와 빈 공간도 줄였다. 제목·수치·비용·조건·남은 시간·조작과 구체적인 실패 이유를 남기고, 씨앗 재고·음식 품질·자동 회복 기준·예약 환불·백업 필요성은 짧게 표시한다.

기록의 긴 사건 문구는 표시할 때만 축약하고 story/guide는 목록에서 제외한다. 복귀의 중복 사건 목록과 수동 중지 뒤 귀환 안내도 제거했다. 실제 사건·중지 사유와 저장 데이터는 보존한다. 독립 감사에서 지역/적 이름·손실 수치를 포함한 표시67사례를 확인했다. 엔진·콘텐츠·저장·아트는 변경하지 않았으며 [결정 D-015](DECISIONS.md)에 적용 범위를 기록했다.

UI 담당은 1440/768/390px의 메뉴·마을 탭·모달51화면을 확인하고 마지막 수동 중지 표시도 세 크기에서 다시 검수했다. root는 기존 브라우저 검증을 실행해 실제 활동·교역·농사·납품·설정·저장·복귀를 확인했다. 삭제한 제작 설명 펼침 검사1개는 제거했고, 초기화 취소 버튼의 바뀐 이름에 맞춰 선택자를 수정했다. 최초 병렬 실행 중 진입 대기 시간이 초과한 기존 흐름 검증은 순차 실행으로34개를 모두 통과했다.

- 주인공 한 명의 직접 활동, 숙련 7종·아이템87종·채집18개·제작법36개·적18종·전투 태세3종.
- 여섯 지역과 결말, 지역별 음식 품질과 준비 조건, 결말 후 반복 탐험·수비·성장.
- 영구 마을의 자원10종·시설12종×6단계·교역18종, 주민·생활·가공·세금·숙련·수리.
- 순위별 창고 배분·기부·버리기, 건설 예약 공간·완공·취소 전액 반환.

- 독립 텃밭4개·작물6종, 유한 씨앗의 심기·수동/자동 수확·소진·재구입·재파종.
- 활동60개별 마스터리와 정수 산출 나머지, 실제 획득·처치 도감, 납품을 사용하는 목표18개.

- 최대7일 복귀·상한 제외 시간, 가방/마을의 별도 원장, 농사·마스터리 요약·확인·중복 지급 방지.

아트는 built-in `image_gen.imagegen`으로 생성했다. 기존 v2파일12개는 보존하고 [마을 풍경](../assets/images/township/town-village.webp)을 추가했다. 표시 파일 총13개·2,137,972바이트이며 원본·프롬프트·해시는 [manifest](../assets/manifest.json), [마을 생성 기록](../assets/generated-township.json), [아트 기준](design/ART_DIRECTION.md)에 있다.

## 검토에서 발견해 수정한 문제

공유 창고 초안은 음식 포화가 모든 공장을 막고 매분 기부를 요구했다. 자원별 공간과 생산/소비 균형으로 해결해 12종의 1단계 거점은 관리 명령 없이 7일 운영된다. 의뢰 보상이 공간 부족으로 사라지던 문제는 수령 전 공간 검사로 고쳤다. 낮은 효율에서 소수 생산을 계속 버리던 문제는 저장 가능한 나머지 누적으로 해결했다.

오래 보존한 첫 탐험 전투의 과거 절대 공격 시각을 저장 오류로 오인하던 문제를 수정하고 남은 공격 시각으로 재개한다. 이전 저장의 도감에 실제 얻지 않은 새 씨앗을 발견 처리하지 않으며, 불량 복귀 사건 타입과 가방 상한을 넘는 의뢰 보상도 적용 전에 거부한다.

Township 제작에서 예약 재료를 사용할 수 있는 가용성 표시, 재고 갱신 후 펼침/입력/초점, 모바일 메뉴의 배경 초점 이탈, 작은 글씨의 낮은 대비를 함께 고쳤다. 최종 이미지를 직접 열어 발견한 경험치 문구의 둥근 패널 끝 잘림도 내부 여백과 반응형 grid로 고쳤다. [독립 감사](../artifacts/township/independent-audit.json)에 재현·수정·재검증과 코드 해시를 보존했다. 이번 UI 수정에서도 감사의 엔진·데이터·저장·요약 여섯 소스 해시가 일치한다.

### 정규 플레이와 방치

`tests/township-campaign.js`의 세 시드1·7·91은 **자원/능력치 편집 없이 정규 명령만으로** 여섯 지역·모든 시설6단계·18목표·농사37수확을 완료했다. 게임 시간9.5556~9.5608시간, 마을 관리197명령, 수비131승/0패다. 큰 경과는 같은 엔진으로 계산한 검증이며 사람이 실제9시간 접속한 플레이가 아니다. [캠페인 결과](../artifacts/township/campaign.json)에 지역별 성장과 준비를 기록했다.

독립 감사는 정규 명령으로12시설1단계를6.5게임분에 준비한 뒤7일간 기부·버리기·순위·수리 명령0회로 생산 유지와 공간 분포를 확인했다. 완주 거점의 별도7일 검증도 영구 시설·주민·해금·목표를 보존했다. 마지막 순수 계산은 초기 거점 약1.47초, 완주 거점 약2.11초이며 환경 부하에 따라 달라진다.

같은 정규 완주 상태에서 난수만 바꾼10시드의 마지막 지역24시간 실험은 자동 보급을 끄면40~41승 뒤 귀환했다. 보급을 켜면 실제 보급품8,379~8,407개와 주화를 사용해3,608~3,619승·수비384승/0패로24시간 이어졌다. 한 가지 완주 장비/시설 상태의 효과이며 모든 플레이의 무패를 보장하는 결과는 아니다. [비교 결과](../artifacts/township/supply-balance.json)에 조건과 원장을 남겼다.

## 범위와 제약

마을·생산·성장·보급·목표 기능과 이번 요청의 전체 UI 설명 정리는 완료했다. 실제 검증한 브라우저는 Windows Edge이며 모바일은 화면 크기를 바꿔 확인했다. iOS/Android 실기기·Safari·Firefox, 여러 주의 사람 플레이 체감은 실행하지 않았다. 계정·클라우드 동기화·외부 공개 호스팅은 현재 범위에 포함하지 않는다.

이전1.0과 WOS개편은 2026-10-04에 엔진/저장36개·브라우저34개·전체화면41개를 통과했다. 위1.1.0결과가 현재 기준이며 이전 수치가 새 확장을 검증한 것으로 읽히지 않게 구분한다. 초기 지침·스킬·Melvor 참고 사본12개와 출처/해시는 유지한다. 기존 친구 게임과 사용자 전역 설정은 이번 확장에서 변경하지 않았다.
