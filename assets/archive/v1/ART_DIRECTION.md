# 북방 생존 게임 아트 기준

2026-10-04. 사용자가 지정한 TheSevenSimulationRPG의 화풍을 북방 생존 게임에 맞춰 적용했다. 초상·북방 배경 7개를 실제 생성하고 게임용 파일로 저장했다. 여기 적은 구도·수량·파생 크기는 실행자 결정이다.

## 확인한 참고작과 적용 방향

친구 저장소 `../thesevensimulationrpg`의 실제 영웅·몬스터 초상 6장과 `docs/reference/character_portrait_prompt.md`, `.claude/skills/art-prompt/`의 공통 프롬프트를 읽고 이미지를 열어 확인했다. 생성 입력은 `src/assets/art/faces/gpt/hero/archer_1.webp` 한 장을 그림체 참조로 사용했다. 기존 얼굴·의상·종족·아트 파일 자체를 신작에 복사하지 않았다.

핵심은 굵고 어두운 외곽선, 큰 각진 면으로 만든 음영, 탁한 색, 선명한 머리 실루엣, 짧은 상반신이다. 초상은 배경을 포함하지 않는 진짜 투명 이미지로 만든다. 북방의 파란 화면에서 인물은 갈색 옷과 청회색 두건으로 구별하고, 곰·멧돼지는 갈색, 늑대는 회색과 아이보리, 수호자는 돌의 청회색으로 읽힌다.

곰·늑대·멧돼지·사슴은 귀·주둥이·코·목·뿔 등 실제 동물의 골격을 유지하고, 털은 가는 실선 대신 큰 면으로 표현한다. 인간형 몸이나 갑옷을 붙이지 않는다. 최종 유적의 수호자는 같은 선과 면 처리로 돌의 얼굴을 표현한다. 동물의 종별 이미지 하나를 여러 지역의 일반·강한 개체가 공유할 수 있다.

기존 게임의 3×3 후보 시트, 초록 배경 키잉, 죄악·파티·직업별 초상 규칙과 승인 절차는 이 프로젝트에 옮기지 않았다. 신작에는 실제 사용하는 독립 에셋을 한 호출에 하나씩 생성했다.

|---|---|---|---|---|

원본 PNG는 `assets/source/<ID>.png`에 보존했다. [manifest.json](../../assets/manifest.json)에 안정적인 ID, 경로, 원본·파생 크기, 실제 프롬프트 전문, 생성 도구, 참조의 역할, 알파 검사 결과, 출력 해시와 용량을 기록했다. [generated-sources.json](../../assets/generated-sources.json)은 도구가 저장한 원본 경로와 프롬프트를 보관한다. 기본 생성 폴더의 원본도 삭제하지 않았다.

생성에는 built-in `image_gen.imagegen`을 사용했다. CLI/API 생성 대체 경로는 사용하지 않았다. [export_art.py](../../assets/export_art.py)는 원본 복사, LANCZOS 축소와 WebP 인코딩만 수행한다. 인물과 알파를 다시 그리거나 배경을 임의로 제거하지 않는다. 초상은 lossless WebP, 배경은 quality 88 WebP다. 게임이 받는 7개 파일의 총 용량은 1,031,248바이트다.

## 수행한 검수

- 생성 7개를 실제 이미지로 열어 대상, 선·음영의 통일, 동물의 종별 골격과 의도하지 않은 글자·배경 유무를 확인했다.
- 초상 원본 6개 모두 알파 최소 0, 최대 255다. 완전히 투명한 픽셀 비율은 32.3~59.4%로 실제 투명을 갖고 있다.
- 출력 WebP를 다시 열어 크기와 알파 보존을 검사했다. 초상 6개 512×512, 배경 1599×900이며 모두 파일을 정상 해석했다.
- [파란 배경 검수 이미지](../../assets/preview-on-blue.png)에서 초상 6개를 260px과 48px로 함께 확인했다. 귀·뿔·주둥이·두건·돌 왕관 실루엣이 작은 크기에서도 구별되고, 사슴의 뿔이 이미지 안에 들어온다.

이 문서의 검수는 에셋과 합성 미리보기 검수다. 실제 브라우저의 화면 배치·전투 연출·반응형 확인은 UI 통합 검증 결과를 따른다. 새로운 지역 전용 배경이나 개체별 다른 초상은 현재 제작하지 않았고, 대표 배경과 종별 초상을 공유하는 것이 완성본의 범위다.
